ticker

See what a long command is doing, in plain words.

A Claude Code mod. After 30 seconds, a running command gets one line: where it's up to, and what failed.

Without ticker

Cloning requests, install dev deps, run tests1m 0s ›

With ticker

Cloning requests, install dev deps, run tests1m 0s ›
Requests tests running; one timeout test has failed so far

Install

One click, then press Return.

Open in Claude Code →

Or paste into Terminal

claude plugin install ticker --marketplace adamalshoomary/ticker
  • Claude Code desktop app
  • macOS
  • A Claude plan or API key
Other ways to install

Desktop app: + next to the prompt → Plugins → Add marketplace → adamalshoomary/ticker → Add plugin.

Claude Code in a terminal:

/plugin install ticker --marketplace adamalshoomary/ticker

Then run anything long

Any command over 30 seconds gets the line, in subagents too.

At 30 secondsRules count the tests, files and steps.
Every 20 secondsHaiku turns them into one sentence. Every number is checked.
Free modeSet summaries to rules for no model calls.
