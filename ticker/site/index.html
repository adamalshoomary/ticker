ticker

See what a long command is doing, in plain words.

A Claude Code mod. After 30 seconds, a running command gets one line: where it's up to, and what failed.

Install

One click, then press Return.

Open in Claude Code →
  • Claude Code desktop app
  • macOS
  • A Claude plan or API key
Another way to install

Desktop app: + next to the prompt → Plugins → Add marketplace → adamalshoomary/ticker → Add plugin.

Then run anything long

Any command over 30 seconds gets the line, in the background too.

At 30 secondsA line shows under the command: how far it is, and what failed.
Haiku, the defaultHaiku writes a sentence from ticker's counts, and every number is checked. It uses a tiny bit of your plan.
Free modeticker writes the line from its own counts. It costs nothing. Type /ticker to switch.
