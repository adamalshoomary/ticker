ticker

See what a long command is doing, in plain words.

A Claude Code mod for the desktop app. After 30 seconds, a running command gets one line that says where it is up to and what failed. The line goes away when the command ends.

Running the app's unittest suite1m 41s

With ticker

Rotate image test failed; JSON import test is running now1m 43s
22 of 36 tests done, one failure so far: image rotation

Install

One click opens the Claude Code app with the install request typed in. Press Return and Claude installs it.

Open in the Claude Code app →

Or paste this into Terminal and press Return:

claude plugin install ticker --marketplace adamalshoomary/ticker

Then start a new session in the desktop app.

  • Claude Code desktop app
  • macOS
  • A Claude plan or API key
Other ways to install

In the desktop app: click + next to the prompt box, then Plugins, then Add marketplace. Type adamalshoomary/ticker, then click Add plugin.

In a terminal session of Claude Code:

/plugin install ticker --marketplace adamalshoomary/ticker

Then run anything long

Nothing to set up. Any Bash command that runs for 30 seconds gets the line, in the main chat and in subagents.

At 30 secondsThe mod's own rules count tests, files and steps, and show a first line.
Every 20 secondsHaiku turns the counts and the newest output into one sentence. A sentence with a number the rules did not count is refused.
No model at allSet summaries to rules, and the rules write every line for free.
